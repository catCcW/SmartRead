# Legado (阅读) 项目特性分析与借鉴

用户提出希望学习开源项目 [Legado (阅读)](https://github.com/gedoor/legado) 的特性。Legado 是一款在 Android 平台上极受欢迎的开源阅读软件，以其强大的自定义能力和丰富的书源生态著称。

## 1. Legado 核心特性分析

### 1.1 强大的书源系统 (核心灵魂)
- **自定义书源规则**：允许用户通过 JSON/XPath/CSS/Regex 等规则，将任意网页小说网站解析为标准书籍格式。
- **书源管理**：支持导入、导出、校验、分组、排序书源。
- **并发搜索**：搜索一本书时，并发请求多个书源，极速返回结果。

### 1.2 极致的本地解析能力
- **多格式支持**：不仅支持 TXT、EPUB，还支持 PDF、MOBI、UMD 等。
- **智能排版**：TXT 智能断章（正则匹配章节名）、去除多余空行、繁简转换。

### 1.3 高度自定义的阅读器
- **排版引擎**：自定义字体、字号、行距、段距、页边距。
- **主题与背景**：支持纯色、图片背景，支持夜间模式，甚至支持 E-ink 墨水屏优化。
- **翻页效果**：覆盖、仿真、滑动、滚动等多种翻页动画。

### 1.4 完善的书架管理
- **分组与标签**：支持多级分组、自定义标签。
- **本地与 WebDAV 同步**：支持阅读进度、书签、书源的云端同步。

## 2. 智阅 (SmartRead) 的演进方向

结合 Legado 的优点与我们现有的 Tauri + React + Python 架构，智阅的下一步开发重点应调整为：

### 阶段一：强化本地解析与智能排版 (当前重点)
1. **TXT 智能断章**：在 Python 后端实现正则匹配（如 `第[0-9一二三四五六七八九十百千万]+章`），将 TXT 自动切分为目录结构。
2. **EPUB 深度解析**：除了 PDF，增加对 EPUB 格式的完美支持（提取目录、样式、图片）。
3. **阅读器排版设置**：在 React 前端增加侧边栏或底部面板，允许用户实时调整字体大小、行距、背景色（护眼、夜间、羊皮纸等）。

### 阶段二：引入“书源/插件”机制 (进阶)
1. **Python 爬虫插件**：利用 Python 强大的网络请求和解析能力（BeautifulSoup/lxml），设计一套类似 Legado 的 JSON 规则引擎。
2. **网络搜索与导入**：允许用户输入书名，后端根据规则抓取网络内容并生成本地书籍。

### 阶段三：数据管理与同步
1. **SQLite 本地数据库**：使用 Python 的 `sqlite3` 或 `SQLAlchemy` 替代目前的内存数组，持久化存储书籍信息、阅读进度、高亮笔记。
2. **多维分组**：实现类似 Legado 的网格/列表视图切换，以及灵活的标签管理。
