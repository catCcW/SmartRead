# 智阅 (SmartRead) - 技术栈与依赖库版本说明

本项目采用 **Tauri + React (前端) + Python FastAPI (本地微服务)** 的混合架构。这种架构既能保证拥有媲美「微信读书」的极美现代化 UI，又能利用 Python 强大的 AI 和文档解析生态。

以下是本项目所使用的核心技术栈及推荐版本说明：

## 一、 运行环境基础

| 环境/工具 | 版本 | 说明 |
| :--- | :--- | :--- |
| **Node.js** | `v24.15.0 (LTS)` | 前端 React 与 Tauri 构建依赖的运行环境。 |
| **Python** | `v3.10+` | 本地 AI 微服务与文档解析引擎的运行环境。 |
| **Rust** | `最新稳定版` | Tauri 框架的底层编译语言（打包桌面端必需）。 |

---

## 二、 前端技术栈 (Tauri + React)

前端主要负责 UI 渲染、用户交互（如划词高亮、翻页）以及与 Python 后端的通信。

| 库/框架名称 | 推荐版本 | 核心作用 |
| :--- | :--- | :--- |
| **Tauri** | `^2.0.0` | 桌面端打包框架。相比 Electron，它使用系统原生 WebView，打包体积极小（通常 < 10MB），内存占用极低。 |
| **React** | `^18.2.0` | 核心前端 UI 框架。 |
| **Vite** | `^5.0.0` | 极速的前端构建工具。 |
| **Tailwind CSS** | `^3.4.0` | 原子化 CSS 框架，用于快速构建类似“微信读书”的极简、毛玻璃、现代化 UI。 |
| **Zustand** | `^4.5.0` | 轻量级状态管理，用于管理当前阅读进度、高亮笔记状态。 |
| **Lucide React** | `^0.350.0` | 精美的开源图标库。 |
| **Epub.js** | `^0.3.93` | 专门用于在 Web/Tauri 中渲染 EPUB 电子书，支持分页和高亮。 |
| **PDF.js** | `^4.0.0` | Mozilla 开源的 PDF 渲染引擎。 |

---

## 三、 后端技术栈 (Python 本地微服务)

Python 作为“隐形”的本地服务器运行，专门处理 CPU 密集型任务（解析、切片、向量化）和网络请求（调用大模型）。

| 库/框架名称 | 推荐版本 | 核心作用 |
| :--- | :--- | :--- |
| **FastAPI** | `^0.110.0` | 提供极速的 RESTful API，供 Tauri 前端调用（如上传书籍、请求 AI 标注）。 |
| **Uvicorn** | `^0.29.0` | FastAPI 的 ASGI 服务器。 |
| **PyMuPDF (fitz)** | `^1.24.0` | 极其强大且快速的 PDF 解析库，能精准提取文本和坐标。 |
| **EbookLib** | `^0.18` | 用于解析 EPUB 文件的底层结构。 |
| **BeautifulSoup4** | `^4.12.0` | 配合 EbookLib 清洗和提取 EPUB 中的 HTML 文本。 |
| **LangChain** | `^0.1.0` | AI 编排框架，用于实现文本切片 (Text Splitter) 和 RAG 检索流程。 |
| **OpenAI SDK** | `^1.14.0` | 官方 Python 客户端，用于对接 GPT-4o 或 DeepSeek 等兼容 API。 |
| **FAISS-cpu** | `^1.8.0` | Meta 开源的本地向量数据库，用于在内存中实现 RAG 的快速检索，无需安装独立数据库软件。 |

---

## 四、 架构通信流程

1. **启动**：Tauri 启动时，通过 Rust 的 `Command` 模块在后台静默启动 Python FastAPI 服务（例如运行在 `http://127.0.0.1:8000`）。
2. **导入书籍**：用户在 React 界面选择文件，Tauri 将文件路径发送给 Python 后端。
3. **解析与 AI**：Python 后端解析书籍，进行切片，或调用大模型生成“滑窗标注”和“思维导图 JSON”。
4. **渲染**：Python 将处理好的 JSON 数据返回给 React，React 结合 Tailwind CSS 渲染出极美的阅读界面和动态标注。
